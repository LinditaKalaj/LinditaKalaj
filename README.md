# Hi, I'm Lindita

I'm a software engineer in New York. Most of my work lately has been backend systems, AI, and automation.

I like building things that can actually run on their own, not just demos that work once. That has included a newsletter that researches and writes itself, a meeting transcription pipeline, RAG over thousands of documents, and a computer vision agent that controls devices.

## What I'm working on now

### [SyndicateBox](https://syndicatebox.com)

I'm building the platform behind SyndicateBox with TypeScript, Next.js, Node.js, Postgres, and Drizzle.

Each newsletter researches local sources, drafts the issue, places ads, and sends itself automatically. The largest region currently has 1,100 subscribers.

I also built the Stripe flow advertisers use to buy placements and moved our email delivery from Postmark to Amazon SES.

## Other things I've built

### [Clippy Desktop Pet](https://github.com/LinditaKalaj/Clippy-Desktop-Pet)

I rebuilt Clippy as a desktop app that lives on your screen and lets you chat with it.

Built with Python and PyQt.

### [Vector Robot Controller](https://github.com/LinditaKalaj/Vector-Remote-Control)

A desktop app for controlling an Anki Vector robot, including movement, animations, speech, and camera controls.

Built with Python.

### Split Check

An Android app that reads a restaurant receipt from a photo and lets people split the bill by item.

Built with Java, ML Kit, and SQLite.
